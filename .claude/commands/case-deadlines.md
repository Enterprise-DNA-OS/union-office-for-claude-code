# case-deadlines

Run `npm run union -- case-deadlines`. Fill in the operator's values. Add `--json` when you need every field.

Each row is a statutory time limit still running. Under 14 days is urgent. Never tell the operator a limit has passed without saying the date the record shows; the event date may be wrong and the organiser must check it.

Nothing here sends a message or contacts anyone.
