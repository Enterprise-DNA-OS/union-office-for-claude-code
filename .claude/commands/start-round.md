# start-round

Run `npm run union -- start-round <agreement> --code=B-XYZ-2027 [--status=preparing|initiated|bargaining|ratifying|settled|abandoned] [--initiated=YYYY-MM-DD] [--next-meeting=YYYY-MM-DD] [--claims=]`. Fill in the operator's values. Add `--json` when you need every field.

Present the result as a short table with codes and dates. If it is empty, say so plainly. Never guess a record that is not there.

Nothing here sends a message or contacts anyone.
