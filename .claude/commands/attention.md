# attention

Run `npm run union -- attention`. Fill in the operator's values. Add `--json` when you need every field.

Lead with anything with days left under 7 or already negative. Group by organiser if the operator asks "who needs to do what". For a deadline, name the rule and its source from the row. Offer the matching draft: a grievance letter, an entry notice, a remittance query or an arrears reminder.

Nothing here sends a message or contacts anyone.
