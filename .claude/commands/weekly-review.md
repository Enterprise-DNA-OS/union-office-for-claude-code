# weekly-review

Run `npm run union -- weekly-review`. Fill in the operator's values. Add `--json` when you need every field.

Run it, then read the draft it wrote and give the operator the five things that matter this week in plain sentences: deadlines first, then money, then bargaining, then organising. Name the draft file.

Nothing here sends a message or contacts anyone.
