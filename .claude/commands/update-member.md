# update-member

Run `npm run union -- update-member <member> [--status=] [--workplace=] [--method=] [--dues=] [--left=YYYY-MM-DD] [--email=] [--phone=]`. Fill in the operator's values. Add `--json` when you need every field.

Present the result as a short table with codes and dates. If it is empty, say so plainly. Never guess a record that is not there.

Nothing here sends a message or contacts anyone.
