# export

Run `npm run union -- export [--out=exports/2026-11-16]`. Fill in the operator's values. Add `--json` when you need every field.

Writes every table to CSV and JSON plus a manifest into a new folder. Keep exports out of Git: they hold member records.

Nothing here sends a message or contacts anyone.
