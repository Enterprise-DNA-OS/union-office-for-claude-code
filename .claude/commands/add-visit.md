# add-visit

Run `npm run union -- add-visit --code=V-401 --workplace= --organiser= --on=YYYY-MM-DD [--permit=] [--notice=YYYY-MM-DD] [--purpose=]`. Fill in the operator's values. Add `--json` when you need every field.

Present the result as a short table with codes and dates. If it is empty, say so plainly. Never guess a record that is not there.

Nothing here sends a message or contacts anyone.
