# draft-entry-notice

Run `npm run union -- draft-entry-notice <visit>`. Fill in the operator's values. Add `--json` when you need every field.

AU only. Writes the notice content to drafts/ with a warning if the permit or timing is wrong. The operator checks it against the current Fair Work Commission form before it goes.

Nothing here sends a message or contacts anyone.
