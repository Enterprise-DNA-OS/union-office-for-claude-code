# add-delegate

Run `npm run union -- add-delegate <member> [--role=delegate|hsr] [--elected=YYYY-MM-DD] [--term-ends=YYYY-MM-DD] [--trained=YYYY-MM-DD]`. Fill in the operator's values. Add `--json` when you need every field.

Present the result as a short table with codes and dates. If it is empty, say so plainly. Never guess a record that is not there.

Nothing here sends a message or contacts anyone.
