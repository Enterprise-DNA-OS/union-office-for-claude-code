# add-member

Run `npm run union -- add-member --no=U2001 --first= --last= --workplace= [--method=payroll|direct_debit|manual] [--dues=8.50] [--email=] [--phone=] [--occupation=] [--joined=YYYY-MM-DD] [--status=active]`. Fill in the operator's values. Add `--json` when you need every field.

Present the result as a short table with codes and dates. If it is empty, say so plainly. Never guess a record that is not there.

Nothing here sends a message or contacts anyone.
