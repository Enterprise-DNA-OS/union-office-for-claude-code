# compliance

Run `npm run union -- compliance`. Fill in the operator's values. Add `--json` when you need every field.

Read docs/compliance.md first: each rule, its source and what a breach looks like. Report as a table: rule, record, what is wrong, due date, days left, source. Breached first, then due within 7 days. For each, say the fix (update-case, start-round, update-visit) and offer the draft. If a rule in docs/compliance.md looks out of date, say so and stop: the operator confirms the law, then you update the doc and the view together in a new migration. Nothing here is legal advice.

Nothing here sends a message or contacts anyone.
