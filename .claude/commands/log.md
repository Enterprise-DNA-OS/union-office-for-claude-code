# log

Run `npm run union -- log <member> --body="..." [--kind=call|visit|email|meeting|note] [--on=YYYY-MM-DD]`. Fill in the operator's values. Add `--json` when you need every field.

Log every call, visit or meeting the operator mentions, with what was said. This keeps the quiet list honest.

Nothing here sends a message or contacts anyone.
