# draft-grievance

Run `npm run union -- draft-grievance <case>`. Fill in the operator's values. Add `--json` when you need every field.

NZ personal grievances only. Writes a letter skeleton to drafts/ with the 90-day date as an office note. The organiser fills in the facts and remedies. Never send it.

Nothing here sends a message or contacts anyone.
