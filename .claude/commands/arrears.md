# arrears

Run `npm run union -- arrears`. Fill in the operator's values. Add `--json` when you need every field.

Split by dues method. Payroll members in arrears usually mean an employer stopped deducting: check `remittances` for that employer before contacting members. Direct debit and manual payers get a friendly reminder: offer `draft-arrears <member>`.

Nothing here sends a message or contacts anyone.
