# help

Run `npm run union -- help` and present the list grouped as: the week (attention, weekly-review, compliance), dues (arrears, remittances, remittance-gaps), cases (cases, case-deadlines), bargaining and organising (bargaining, density, delegates, quiet, visits, permits), records (member, members, log and the add and update commands), and moving data (import, export). Mention /customise and /new-view last.
