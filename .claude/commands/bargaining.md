# bargaining

Run `npm run union -- bargaining`. Fill in the operator's values. Add `--json` when you need every field.

NZ rows show when the union can initiate bargaining (60 days before expiry, 120 for a multi-employer agreement). AU rows show nominal expiry. Flag any agreement inside its window with no initiated round. Offer `quiet` to see who to talk to before bargaining.

Nothing here sends a message or contacts anyone.
