# add-case

Run `npm run union -- add-case --code=C-301 --member= --kind=personal_grievance|unfair_dismissal|general_protections|dispute|claim --jurisdiction=NZ|AU --event=YYYY-MM-DD [--organiser=] [--summary=] [--sexual-harassment] [--next-step=] [--due=]`. Fill in the operator's values. Add `--json` when you need every field.

Present the result as a short table with codes and dates. If it is empty, say so plainly. Never guess a record that is not there.

Nothing here sends a message or contacts anyone.
