# remittances

Run `npm run union -- remittances`. Fill in the operator's values. Add `--json` when you need every field.

A negative difference means the employer sent less than the authorised deductions add up to. Days since period over 35 means no new file. For either, run `remittance-gaps` and offer `draft-remittance-query <employer>`.

Nothing here sends a message or contacts anyone.
