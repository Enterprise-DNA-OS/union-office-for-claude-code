# draft-remittance-query

Run `npm run union -- draft-remittance-query <employer>`. Fill in the operator's values. Add `--json` when you need every field.

Writes an email to the employer's payroll contact in drafts/. Never send it.

Nothing here sends a message or contacts anyone.
