# remittance-gaps

Run `npm run union -- remittance-gaps`. Fill in the operator's values. Add `--json` when you need every field.

These members authorised payroll deductions but were not on the employer's latest schedule. Check each member has not left or changed jobs (`member <no>`) before querying the employer.

Nothing here sends a message or contacts anyone.
